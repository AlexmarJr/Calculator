A test that confirms an error is reported does not establish that the user can
successfully retry after the network recovers. Recovery of a pending calculation
after a transport failure still needs a regression test and a code correction,
as identified in the project review.

Backend validation and action processing still have uncovered statements;
ValidateState has 68.4% statement coverage. The report does not measure Go
branch coverage, and a function's statement percentage is not a count of all
possible input combinations or execution paths.

Passing tests and high coverage do not prove that all calculator behavior is
correct. Coverage describes executed code, not the quality of assertions.

5. REPRODUCING THE MEASUREMENTS
------------------------------

Run each block from the indicated directory. Keep Go, Node, npm, and installed
dependencies in the same operating system environment. For a project stored in
WSL, execute local development and test commands inside WSL.

Backend, from backend/:

  go test -count=1 -coverpkg=./api/... -coverprofile=coverage.out ./...
  go tool cover -func=coverage.out

Optional HTML visualization of the same Go profile:

  go tool cover -html=coverage.out -o coverage.html

Frontend, from frontend/ with Node.js 24 LTS:

  npm ci
  node --experimental-test-coverage --test "tests/**/*.test.ts"

To save the frontend console report as text in Bash/WSL:

  node --experimental-test-coverage --test "tests/**/*.test.ts" > coverage.txt 2>&1

The frontend command runs TypeScript tests using Node's native support.
It does not load React components or automatically instrument unimported files.

Alternative using Docker, from the project root:

  docker build --target build -t calculator-backend:audit ./backend
  docker run --rm calculator-backend:audit sh -c 'go test -count=1 -coverpkg=./api/... -coverprofile=/tmp/coverage.out ./... && go tool cover -func=/tmp/coverage.out'

  docker build --target build -t calculator-frontend:audit ./frontend
  docker run --rm calculator-frontend:audit node --experimental-test-coverage --test "tests/**/*.test.ts"

Docker commands above print the measurements. The Go profile inside the
temporary container is removed when that container exits. This text file is
the human-readable coverage report retained for the assignment.
